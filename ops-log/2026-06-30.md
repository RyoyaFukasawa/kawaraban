## プロジェクト改善考察

**fetch の仕組みは妥当か**:
fetch 自体は正常稼働。BBC・The Hill の 403 継続（7週以上）は仕組みの問題ではなく bot 遮断の問題で、User-Agent 調整が依然未着手。CBS /transcript/ は PR #15 未マージで毎日混入が続くが、今回の選定では手動で除外できた。

**本当に最新・先進の情報が取れているか**:
今日は Anthropic Claude Sonnet 5（TechCrunch＝一次情報同日）、Etched（TechCrunch）、Realta Fusion（TechCrunch）、NVIDIA Omniverse（公式ブログ）など複数の一次情報当日取得ができた。AI枠では OpenAI GeneBench-Pro も同日取得。Anthropic Blog が追加されていれば Sonnet 5 を公式ブログから直接取得できた点で惜しい。

**ソース構成の穴**:
1. **Hugging Face の description 空欄問題** — 継続。今日3件全て空欄で不採用となった。HF Blog は LLMの論文・モデルリリースの重要な一次情報源であり、本文取得か description 改善が急務。
