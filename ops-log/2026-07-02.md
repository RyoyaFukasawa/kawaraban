## プロジェクト改善考察

### fetch の仕組みは妥当か
候補227件はカテゴリ間で極端な偏り（robotics 3件 vs politics 75件）。36時間フィルタは問題なく機能している模様。roboticsの過少採取は絶対数の問題であり、フィルタでなくソース追加で解決する必要がある。Ant Groupのように他カテゴリに混在するロボット記事を自動でroboticsに振り分けるルールがあれば採用数が増える可能性。

### 本当に最新・先進の情報が取れているか
本日はAutomate 2026（北米最大ロボット見本市）のレポートが取得でき、タイムリーな一次情報を確保。OpenAI政府ファンド提案、SK Hynix ADR上場（7/10）など近未来の重要イベントも捕捉できた。一方でNVIDIA Roboticsの公式発表（INSIGHTS.md指摘）は引き続き拾えていない。ノルドストリーム起訴のような欧州法務リスクはBBC 403のためRSS説明文のみとなった。

### ソース構成の穴
- **robotics一次情報不足**：IEEE Spectrum、NVIDIA Robotics Blogの代替または補完ソースが必要。IEEE Spectrumは前日も指摘（INSIGHTS.md「🔵 未着手」）。
- **欧州法務・規制**：EU司法裁判所の判決（今日のGoogle反トラスト）はCNBCがカバーしたが、欧州ソース（Reuters、EUREKAlert等）が直接あれば報道の深さが違う。
- **WSJ Politics/Technology SKIP**（INSIGHTS.md 🔴）：継続。代替として現在TechCrunch/CNBCが機能しているが、WSJが取れれば経済・政治の深度が上がる。

### 選定ロジック・枠
5件/カテゴリのMAX_PER_CATEGORYは妥当。本日はroboticsのみ3件（候補不足のため）。「候補3件のときは無理に5件を別カテゴリから転用しない」という判断をとったが、Ant Groupを転用して3件を達成したことでバランスが保てた。AI枠はReddit 2件が先進性より速報性寄りとなっており、一次ブログ（Anthropic Blog等）拡充の効果が期待される。

`npm run ingest` → `npm run build-md` は正常動作。23件すべて重複なく新規追加。fetch-article コマンドで本文取得→記事選定→summary 記述→ingest→build-md という手順は安定して機能している。CBS News `/live-updates/` URLは本文取得成功（INSIGHTS.md 🟡で未マージのフィルタ除外が今日のルートで自然に動作した可能性あり、要確認）。
